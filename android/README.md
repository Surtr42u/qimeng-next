# Android 客户端

独立 Kotlin / Compose 客户端，应用包名 `media.qimeng.next`。客户端不拥有媒体业务数据库或双向备份合并。用户已明确保留本机离线与远程双模式：可移除 embedded 模块运行同一个新 Go 服务，装配契约见 [本机运行模块](embedded/README.md)，基础启停、登录和证书更新已在云端本机仪器运行。业务与数据层从空目录编写；用户授权复用旧纯展示 UI 以保持界面一致，复用清单与边界见 [UI 来源](UI_SOURCES.md)。

云端提供两种开发用 APK，最低系统版本声明为 Android 8.0（API 26）。连接现有 PC/NAS 影库，选 `Cloud verification` 中 `android` 作业的 `android-first-check` 制品。需要手机离线运行，选 `android-embedded` 作业的 `android-embedded-check` 制品。下载前核对对应作业和提交。首次打开后按运行模式选「NAS / 电脑」或「本机」。云端模拟器与真机验收进度见[当前状态](../docs/status.md)。

两种 Next APK 共用 `media.qimeng.next`，旧安装版 `74597408` 使用 `media.qimeng.app`。实际手机交付选对应主线 SHA 的 APK，先核对包名、证书和目标，保留两套应用各自的数据。所有者只授权后台时，核查限于明确指定的物理设备与允许的状态，不自动亮屏、启动到前台或截图。Compose 实际画面在允许屏显后单独验收。[主线包与设备交接](../docs/handover.md) · [旧版构建声明](https://github.com/Surtr42u/qimeng-media/blob/745974081716a9d69a95002a41220e35e743d764/android/app/build.gradle.kts)

## 分层

Gradle 的有效变体依赖、生产源集、纯客户端 APK 及服务决策回读由[模块门禁](architecture/README.md)记录。已安装版本的同场景截图采集见[旧版截图基准](baseline/README.md)。

- `core/model`：端内展示、传输和队列模型，不计算推荐、排名、统计与命名规则。
- `sdk`：引用 `api/generated/kotlin/src/main/kotlin`，源码仅由云端按 OpenAPI 生成。
- `core/data`：生成 SDK 的唯一业务调用边界，Repository 将 DTO 映射成端内模型；媒体引擎经限定来源的认证客户端取字节。
- `core/ui`：独立于业务的主题、卡片、经典底栏，以及旧版的 `FloatingTabDock`、`QimengBackdropState` 和 `BackdropGlassPanel`。可由其他 Compose 应用通过适配层复用。
- `app`：ViewModel 管理查询代际、会话与用户草稿；页面只调用 ViewModel，不引用 SDK。

主要导航保留首页、相册、数据、我的；上传、报告、作者、历史、收藏和设置经原类型入口进入。换服务器时清除旧实例的详情与报告，持久传输仍绑定原地址与实例身份。队列中其他服务器的记录保留，切回其原服务器后即可查看报告和媒体。

2026-11-17 界面复核确认当前页面结构存在偏离，不能把功能接线称为旧版界面已保留。具体源码对照、纠偏顺序与截图缺口见 [现行界面对照](UI_PARITY.md)；当前直接恢复旧版已使用的布局、材质档位及路由切换。

## 当前源码行为

词表数据层从 Go 读取标签的稳定 ID、正式名称、别名和修订。按旧称搜索后，正式名称变动仍能识别同一标签。翻页请求带上当前搜索词，迟到结果按请求代次核对。用户提交标签时可独立读取词表。[词表协议](../docs/api.md)

播放进度由绑定当前内容版本的 Media3 监听器送入本机持久事件队列。拖动、暂停、播放完毕和离开时都会保存实际位置。同一位置的连续通知合成一次。重新打开时从 Go 读取当前内容版本的续播点。

登录恢复原本机 / NAS 双模式页。NAS 密码只用于交换可撤销会话，不保存密码；最近 5 个成功地址持久保留。旧默认登录偏好与成功登录跟随、服务器设置卡片顺序和本机地址预填流程已接回；预填地址在登录确认后才用于启动。本机入口启动独立运行模块，再以私有回执的临时 TLS leaf 证书认证连接；远程使用系统证书信任（或本机隧道的 loopback HTTP）。服务会话保存在 Android Keystore 加密的私有配置中，备份关闭，传输记录不保存令牌。客户端禁用重定向，不把媒体认证转送其他来源。设置中的退出会撤销服务器会话；更换连接仅清除本机选择，原目标传输保留。

自动发现先匿名核对最多 5 个已记住地址（每个至多 2 秒），再进行 12 秒有界 DNS-SD，最多保留 32 个候选。正式服务类型 `_qimeng._tcp`，使用 SRV 实际端口和 `txtvers=1/api=0.1.0/id/scheme/path=/api/v1`；可选 `origin` 必须是无凭据 / 查询 / 路径的 HTTPS 根地址。发现不发送密码或保存令牌，不改变 TLS 信任；选中候选后登录仍先回读实例 ID。HTTP 局域网候选不能绕过 HTTPS / 隧道登录约束。API34+ 使用服务更新回调，较旧版本顺序 resolve；离开登录页或退后台停止发现并释放监听。暂不把带接口作用域的 IPv6 地址去掉作用域后使用。依据：[Android NSD](https://developer.android.com/reference/android/net/nsd/NsdManager)、[服务 TXT 与地址 API](https://developer.android.com/reference/android/net/nsd/NsdServiceInfo)。解析和候选已接线。远程登录已实际运行，真实多设备 DNS-SD 与旧版截图对照另行验收。

首页的普通推荐和排行榜只展示普通作品，COS 入口展示 COS。相册的全部分区可跨区浏览。静态图片和视频卡片加载版本化缩略图。浏览页支持分区、标签、影库与作者等筛选、游标续页和 2–5 列网格。

视频海报可横滑切件。播放器沿用旧版双排控件、默认静音、点按显隐、双击播停、横拖定位和长按临时 2 倍速。横屏视频可固定横屏全屏，在同一 Media3 输出上连续播放。系统返回依次退出全屏、回到海报和离开详情，离开时释放播放器。时间轴标记可以新建、编辑、删除和跳转，标记和续播点绑定原内容版本。图片详情支持缩放平移、单指切换、标签、备注、作者编辑、收藏和每日点赞。

「我的 → 数据管理 → 备份与存储 → 缩略图缓存」显示服务器和本机最近所选实例在手机上的 JPEG 文件数及实际占用。确认清空只移除该卡实例的手机缓存。内嵌端的当前 md 生成覆盖从 Go 读取。两池使用 Coil 私有 LRU，默认上限分别为 1 GiB 和 512 MiB。条目核对实例、资产 ID 和内容版本，回环证书更新时沿用同一内嵌实例的预览。当前协议只向同一实例的所有者签发 Android 登录会话。动图网格继续播放原件，原件请求禁用磁盘缓存。

登录后和已登录冷启动自动分页补拉 md。页面处于前台时预取单路运行，让出浏览请求。远程需要非计费网络，本机经回执的证书直连。版本未变且磁盘已有条目时跳过缩略图网络请求，清空活动实例后等下次登录或进程重启补齐。普通图片网格、视频海报和预取共用同一 Coil 条目。[缩略图协议](../docs/api.md) [Coil 3.1.0 DiskCache](https://github.com/coil-kt/coil/blob/3.1.0/coil-core/src/commonMain/kotlin/coil3/disk/DiskCache.kt)

浏览与播放携带稳定会话身份；停留用单调时钟按前台区段记录，每 30 秒、暂停或离场入持久队列，不记录不足一秒的区段，后台不计时。进度是独立事件，不当作浏览次数。切换服务器时，离场记录仍带原实例目标。统计概况、趋势、24 小时浏览回顾与兴趣份额全部消费服务器结果，推荐偏好读取服务器四预设，保存成功后才更新选中态。

在「资料维护 → 备份恢复 → 同步浏览数据」或上传页查看当前连接的待补传数。回收站项恢复后可补传，暂时的传输失败自动重试，服务明确拒绝与旧版仅保留文字的结果可以逐条核对。清理需要逐条确认，重试沿用原事件、资产、内容版本和会话标识。每个地址及实例独立计算 1,000 条待补传或待处置的额度，最多另保留 200 条已拒绝记录。超过预留额度的拒绝仍占普通额度，直到用户核对清理。

详情的「收藏」和「点赞」分别向 Go 提交所点按钮的目标状态。今天已点赞时再点同一胶囊可取消今日赞，按钮计数读取服务端给出的累计值。旧资料无法判定今天是否已经计票时显示服务端冲突原因。请求结果不确定时，重试同一界面修订的同一操作会使用原幂等键。

SAF 批选先保存待传快照，允许改名后提交；系统分享可用已选择的目标直接提交，未登录/未选择位置时保留待传项。普通上传为默认，智能整理显式选择。可浏览/创建库内目录、选择本批多作者、组图/短剧集合、获取渠道及备注；编号只由 Go 决定。文件提供器字节先复制到应用私有空间，以固定重试输入；原件不删除。WorkManager 按原操作身份恢复批次、上传句柄及服务器 offset，再传分片；失败项不阻塞其他独立文件。取消先持久化，成功入库与等待智能整理分别报告。读取失败的输入逐项保留本机结果。清理传输记录不删除服务器媒体。私有副本存在手机可用空间预算。

原始选择在读取字节前逐项取得稳定 inputId 并持久保存；每批至多 100 项，超出时完整拒绝，不截断。提交时把完整清单（包括读取失败项）先封存到 Go，再创建上传，清单指纹与输入次序一同持久化。无法读取原名的输入使用 nameState=unavailable 并省略原名，序号提示仅用于显示。可得的 SAF 原始修改时间随上传保留；无法得知时省略，不拿入队时间冒充。取消通过服务器输入接口确认，尚未拿到 uploadId 也可取消；发布已开始时保留待核对状态。取消确认前不清掉本机记录，任务报告按原始清单展示未到达输入，不以收到的文件数量伪报整批完成。

文件提供器声明的零字节、以及读到末尾确认的零字节都会写入原始清单。后台任务按稳定输入 ID 回读 Go 逐项结果，空文件与不支持的格式显示失败原因，可清理本机记录。合格项继续普通入库或等待智能认领；已选择的作品命名和集合规则继续生效。旧队列在恢复时也会核对已封存的报告。

管理入口包括作者创建/编辑/关注/删除/合并、标签词表、原作与角色词表、影库启停、媒体改名移动和回收站恢复；永久删除是回收站内单独确认的操作。同组入口仍逐件展示媒体。常规作者与 COS 能力分开；修改携带基础修订，冲突保持草稿与明确错误，不静默覆盖。标签草稿保留打开时的关系修订，刷新不会自动给旧整组草稿套上新修订；全局已删除标签只能通过明确的“添加”请求重建。获取渠道和原作/出处是不同字段。

作者资料按 X / 基本资料 / 其他账号分别读取和保存，候选需用户载入草稿并明确保存；部分候选中缺失的字段保留当前值，显式空值表示清除。修改简介原文时不沿用未核对的旧译文。头像只加载当前实例认证的缓存地址，远程网址交由服务器获取；本地头像经系统文件选择上传。合并与删除保留档案为只读入口。

AI 接入默认可读取全库。新增接入时依次选择动作、指定范围与预算、核对后创建。一次性凭据在防截屏弹窗中默认遮罩，可按需显示或直接复制到可信执行器，关闭后从本页清除。在有效、过期、撤销与全部记录中展开「权限详情」，可查看服务端签发的范围、来源、候选与直接维护字段、单帧识图权限、授权有效期和各项任务预算。

「范围与预算」中的「允许单帧识图」默认关闭，需要选择媒体库、开启研究及接收文件或已有作品预览，并填写正数研究预算。逐项核对后创建的授权可用于明确申请单帧外发的受限任务。[外部查证权限与配置](../docs/api.md#单帧反向查证)

## 材质和动效

外观页沿用旧版的四个底栏材质选项。默认液态玻璃，其他选项为磨砂玻璃、纯色坞和经典导航。前三档复用旧版 FloatingTabDock，经典档使用原 Material3 NavigationBar 的布局和颜色。首页搜索框与两个图标随材质启用原内容采样。覆盖页隐藏底栏，视频直接绘制在自己的窗口中。

页面直接切换，顶部推荐、COS 与排行榜点按芯片时直接换页，仍可手指横滑。保存容器恢复此前页面的草稿和滚动状态。同一主标签 400 毫秒内二击回顶。跟随系统减少动画，屏幕阅读器仍可读取标签名称与选中态。云端仪器采集四档材质的独立截图。

## 云端构建

应用构建作业以 Temurin 21 运行 Gradle 9.7.0，使用 Android SDK 37 和 Build Tools 37.0.0。Android 模块的 Java 源与目标兼容级别为 17，纯 JVM 模块使用 17 工具链。应用 targetSdk 与云端仪器模拟器均为 35。[构建配置](app/build.gradle.kts) · [云端工作流](../.github/workflows/prepare.yml)

`generate` 先提供同提交的 Kotlin SDK。纯客户端作业 `android` 关闭 embedded，运行 `verifyClientArchitecture`、客户端与核心模块单测和 `:app:lintClientDebug`。架构任务组装并读取实际客户端 APK。内嵌版在 `android-native` 提供两个架构的原生程序后由 `android-embedded` 构建和检查。[模块门禁与命令](architecture/README.md)

云端专用 API 35 模拟器再运行 `:core:ui:connectedDebugAndroidTest :core:data:connectedDebugAndroidTest`。这些测试覆盖快速切换只有一个活动页面、草稿恢复、减少动效、选择语义、大字/深色导航，以及队列重建、坏记录不伪装空队列、认证同源/重定向/断开边界；合成背景截图写入测试应用 external files 目录。JVM 测试另覆盖前后台停留区段、目标实例与查询代际。不得使用本机默认模拟器或手机，也不能访问旧 8420 实例。

真实链路仪器类为 `media.qimeng.next.test.AndroidRealServerTest`：只允许 runner 参数 `qimengServerUrl=http://127.0.0.1:18481/`，`qimengToken` 来自同 SHA 隔离 Go 服务的临时测试凭据。云端将横屏和竖屏 H.264 合成视频放到指定设备。测试通过仅存在于测试 APK 的 ContentProvider 和真实 WorkManager 验证 PNG / 视频入库、标签、收藏、推荐及播放历史。视频用例从首页、相册和作者作品进入，核对暂停拖动提交一次进度、播放完毕重播、横屏进出、后台恢复、解码表面和窗口图像。完整窗口截图存入云模拟器的合成相册，应用卸载后仍可回收。运行命令、显式设备选择及产物回收由云端工作流负责。

client 仪器任务为 `:app:connectedClientDebugAndroidTest`。本机原生产物按 embedded README 云端装配后构建 `:app:assembleEmbeddedDebug`；隔离清空合成应用数据，再单独运行 `:app:connectedEmbeddedDebugAndroidTest`，限定类 `media.qimeng.next.test.EmbeddedRuntimeTest` 且显式参数 `qimengEmbedded=true`。该测试验证受包 Go 在 App UID 下启动、TLS pin 与正常 SDK 登录、同一实例的库数据经停止 / 重启仍在，并要求新启动更换临时证书。不能用这条基础测试代替全部本机媒体 / 后台 / 迁移验收。

锁定版本见 `gradle/libs.versions.toml`。选择已知兼容的稳定版本；官方依据：[AGP 9.3 兼容矩阵](https://developer.android.com/build/releases/agp-9-3-0-release-notes)、[Compose 编译器与 Kotlin](https://developer.android.com/jetpack/androidx/releases/compose-kotlin)、[AndroidX 稳定发布](https://developer.android.com/jetpack/androidx/versions/stable-channel)、[Media3 发布说明](https://developer.android.com/jetpack/androidx/releases/media3)、[Coil 更新记录](https://coil-kt.github.io/coil/changelog/)、[Retrofit](https://square.github.io/retrofit/)、[OpenAPI Kotlin 生成器](https://openapi-generator.tech/docs/generators/kotlin/)。

## 验证和仍在接通的能力

当前云端运行、逐屏截图、已知失败位置见 [Android 界面对照](UI_PARITY.md) 与[仓库状态](../docs/status.md)。

作者 TXT、完整备份和异常决定的服务端协议已进入新仓。Android 对应维护入口分别按实际接线核验。归档文件夹接受持久 SAF 树授权，由 Go 匹配一级目录名并保留库内层级。真实厂商后台、无障碍与真实用户媒体不属于当前云模拟器证据。

连接本机影库后，进入「资料维护 → 设备领取」，点复制按钮取得本机影库标识。要接收视频时间轴标记，可展开「选择本机目标视频」，按文件名搜索，核对所在影库和路径，分别复制目标视频 ID 与内容版本。把这些值交给 PC 或 NAS 上签发设备令牌的管理员。发送端可选择作者资料块、TXT 片段和绑定视频版本的时间轴标记。[原生设备包协议](../docs/api.md)

手机领取协议 2 的 `nativeSelection`，按字节范围续传，核对来源实例、目标实例、包身份与 SHA-256，再按本机 Go 的预检指纹提交。重复发送同一包或丢失响应后，可回读同一组逐项回执。指定视频缺失或换版会写入冲突回执。[原生设备包协议](../docs/api.md)

「后台领取」与「应用时覆盖作者资料」默认关闭。点「保存设置」或「立即应用」会一同保存两项选择，已领取的包继续按领取时的选择处理。开启覆盖只更新前一次由同一来源交付、且在本机没有修改的资料。人工编辑或明确清空的内容受保护。最近设备任务可展开原生包的逐项结果，也可在原收件影库查看旧 v2 回执的计划指纹与检查点。完整备份通过维护目录的当前代或上次代 `.qnext` 和配套离线命令恢复。[迁移与恢复](../docs/migration.md)

手机归档的私有 SQLite 清单仅保存设备读取与传输状态。确认后沿稳定的文件和批次身份复用上传队列，重扫相同清单仍显示原批次。上传到本机时保留来源；远程上传须先取得 Go 对同一输入、版本和摘要的独立备份与回收许可。手机仅对可以重新核实物理身份、字节和摘要的 Android 系统媒体执行有条件的回收操作，并读回系统结果。只读、第三方提供器、原件变化、许可失效和回收状态未知分别留有结果。API 35 云仪器分别覆盖只读合成 SAF 归档和可回收的系统媒体。

实际读取资料：新仓 `AGENTS.md`、`README.md`、`docs/verification.md`、`docs/requirements.md`、`api/openapi.yaml`；规划需求 R01–R23 / 验收对照；旧 Android README 与 `GUIDE_UI` Android 相关段落（仅产品行为参考）；上列官方依赖与图形 API 文档。实现分工与模型证据由仓库 `docs/provenance.md` 统一记录。

普通上传取得 Go 的作品 ID 并保存传输回执后，当前连接的浏览页重新读取服务端列表。刚从空库完成分享上传时，返回首页也会读取新推荐。设备仪器分别核对分享与列表、横屏视频、只读归档和维护目录授权；合成文档提供方按目标 App 分别授予临时 URI 访问权限。

系统分享接收时固定已选服务、库、目录与本次输入身份。Files 暂存中的其他选择继续保留。云端仪器通过实际 SEND_MULTIPLE 发送两份合成媒体和一份不可读输入，校验同一份原始清单与独立手选草稿。相册和收藏的四维筛选、首页 COS 请求源及截图状态见 UI_PARITY。仪器截图使用云模拟器的合成相册 Pictures/QimengNextCloudTests，以便 connected 测试卸载后回收。

上传页恢复固定顶栏、位置卡、默认收起的“作者与来源”、系统文件和待传编辑清单。目录树只读取已展开的分支，父目录和子目录显示 Go 的直接文件数。手选文件在原位编辑基名，扩展名取自原始选择并锁定。Go 的普通 / 智能模式和编号建议放在本批待传区域。资产获取渠道与明确追加到所选常规作者的来源分别保存。详情按名字新增作者与整组关联使用打开草稿时的修订和同一幂等请求。

普通上传可按姓名或别名联想选择已有作者，也可从服务的获取渠道词表点选已有来源。编辑单个文件的基名时，建议由目标库、目录和媒体类别对应的服务端命名范围提供。采用建议只填基名，上传继续使用来源扩展名和原输入标识。

媒体详情的作者面板进入独立「编辑作者与来源」。同页编辑文件名、媒体获取渠道、作者关联和每位作者的来源，改名保留现有扩展名与目录。保存按各对象的修订逐步提交，出现冲突时保留待保存输入和已确认步骤。返回可确认放弃待保存部分。「更多媒体管理」沿用原详情的标签、备注、原作与角色、移动和回收站操作。

「数据管理 → 词表维护 → 原名提取词表」编辑当前服务的自定义出处组、变体、角色别名与停用词。保存按读取的修订提交，服务器重算状态和处理数可以在原页查看。遇到修订冲突时保留草稿，用户确认后可读取新词表。

「我的 → 关于 → 版本信息」读取当前实例的服务端构建版本。连接失败时显示读取结果，并可点击重试。

作品详情内备注、获取来源、出处、角色、改名、回收与作者修改使用用户打开表单时看到的修订和媒体原目标。跨实例切换不会把同 ID 资产的请求发给新实例。播放仪器读取 Go 返回的该资产累计播放数；浏览历史的最近 view 用独立断言核对。

“作者新作”只读取服务端保存的订阅与条目。用户在“资料与维护”中按已核实账号明确设置公开 HTTPS RSS / Atom 地址，点击检查后才请求服务读取；未配置时可打开已确认的发布页。AI 接入的现有作品研究和作者、出处角色、标签、改名字段均须分别勾选并明确选库，旧授权维持其已保存的范围。
