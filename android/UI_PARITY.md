# Android 现行界面对照与纠偏

2026-11-17：用户明确要求保留旧版现行页面结构、导航内容和操作习惯，随后明确授权直接复用旧纯展示 UI；来源登记在 [UI_SOURCES](UI_SOURCES.md)。允许新增的视觉变化仅为已授权的平滑过渡与液态玻璃导航选择效果。新数据层、生成 SDK、持久队列与已有草稿继续保留。下面是源码对照结论，**不是截图验收结果**。

## 已确认差异

## 实施与证据顺序

1. 先恢复四主页面结构和共享紧凑胶囊 / 标题 / 分组样式；导航仍是首页、相册、数据、我的。所有业务仍走新 Repository 和 ViewModel。
2. 同批补齐阻碍旧行为的 API 契约，尤其相册四维、搜索建议、作者计数与排序；不创建无法执行的筛选控件。
3. 恢复详情舞台、搜索三态、作者维护层级和上传清单。已有用户草稿和持久任务不清空；只复用纯展示，不导入旧业务实现。
4. 云端同一合成数据、固定尺寸 / 字号 / 主题录制旧现行基准与新页面；比较入口、层级、间距、文字、可见行数、媒体比例。另验快速切换、首帧、状态恢复、键盘、大字、TalkBack 和减少动效。

当前未取得可用的旧页面合成截图。仓库已跟踪图像中只定位到 launcher 资源；忽略的走查目录可能含真实媒体，未读取图片内容。详情沉浸前后、横屏视频控制栏、首页横滑中间帧、相册展开 / 折叠、搜索三态、作者维护、上传待传清单均缺实际图像基准，不能宣称像素一致。云端比较由根代理协调，不操作本机模拟器或真实手机。
