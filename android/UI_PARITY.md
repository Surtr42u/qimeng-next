# Android 界面对照与验收

旧版 Android 的实际布局、主导航、配色、字体、封面比例和交互是本项目的基准。当前复核按用户指出的旧版实际界面恢复原默认值、选中方式和路由切换。下表区分源码接线与可查看的模拟器结果；有相同控件或通过编译不足以证明旧新版像素一致。
