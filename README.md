# 绮梦 Next

面向个人 PC / NAS 的自托管媒体库。Go 业务核心、React Web/PWA、Kotlin/Compose Android 客户端与独立 AI 工具入口。

本仓库于 2026-11-17 从空目录开始重构。业务核心重新实现；用户明确允许复用旧UI表现层，要求原界面保持一致，只增加已同意的过渡与导航效果。旧业务实现不导入。当前处于开发阶段；可用能力、验证结果及缺口以 [当前状态](docs/status.md) 为准，不应连接既有真实媒体库。

## 产品原则

- 后端可在 PC/NAS 独立运行，也可由可移除的 Android 本机模块离线托管；两种形态共用业务核心，普通上传与浏览不依赖 AI。
- 稳定资产身份、明确内容版本；收藏、历史、作者关系与人工修正受保护。
- 智能批次逐项报告，已授权正常新增自动完成，重复/冲突/替换按实际授权处理。
- AI 工具按任务提供必要上下文，长结果与计划可引用接续，失败不能伪报成功。
- 保持旧版实际界面，复用并优化UI背后代码；仅增加已同意的平滑过渡与液态玻璃导航选中效果。
