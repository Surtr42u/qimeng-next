## 仍需接通或单独验证

- 监控目录按注册位置求和，同卷可重复计入。出现续页时概览标明已读取范围。各系统能提供的 CPU、内存与卷读数取决于宿主系统，浏览器合成图与目标机器实际读数分别验收。
- 作者公开档案及离线头像的源数据保留与真实迁移结果见 [作者资料](author-profiles.md)。已核实身份可保存 RSS/Atom 作品订阅，在作者新作中主动检查。服务端读取保存记录时不会自动访问订阅站点。
- 已有关联在长词表后页时保留原 ID。完整名称须由对应关系查询返回。
- ArtPlayer 使用浏览器视频解码。硬关闭可能丢失尚未落盘的最后停留段。触控、实际格式、PWA 安装、浏览器文件授权和 SVG 材质按目标设备验收。
- Windows 窗口、托盘、安装与卸载分别记录实际结果。Go/浏览器联调以同提交回读为据，合成图片无法代替用户设备或 NAS 迁移验收。

## 动效与视觉边界

独立组件规范见 [ui/README](../ui/README.md)。首页或相册进入详情后，保留下层已加载列表，底衬禁用交互。离开详情回到同一列表时还原滚动与焦点。其他页面的返回记录最多 64 项。图片对话框关闭后焦点恢复到打开按钮。CSS 支持浅深色、减少动效、高对比与透明材质降级。

2026-11-18 按用户要求暂停新增视觉方案。Web/桌面产品入口恢复旧侧栏与顶栏的活动样式、旧页面与卡片 CSS 入场、可保持筛选及滚动位置的首页/相册底衬和独立滚动的详情层。原设置同状态有 1440×800 与 390×844 的两组云图。旧基准现有截图未覆盖首页和相册，源码比对与新合成截图单独记录。
