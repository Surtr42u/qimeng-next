## 需要继续接通的保留能力

这些是当前实施中的缺口，不是用户批准的功能删减；主代理与后端继续补齐后更新本表。

- 推荐、COS推荐、周期排行榜及相同口径的窗口统计/浏览回顾：当前首页保留入口，明确显示能力未就绪；最近入库单独标识。不能以普通排序、库存或事件总数冒充原有结果。
- 完整服务监控/网络与存储明细、库停用移除/扫描设置、来源词表/资料目录、一次性旧v2迁移入口：只有真实后端契约和验收具备后开放写入。
- 原生视频内核不新增，但原有时间轴标记、播放时长、详情停留与离线事件补发需由统一事件协议接通；当前原生播放器能播放/续播，不等同于全部播放器行为已保留。
- 作者完整分字段网络档案、身份核验候选、原文/译文维护需扩展真实档案字段；作者新作自动抓取已按新需求明确不纳入，不能把无源状态画成零更新。
- 更多旧有高级筛选维度、服务端匹配数与统计窗口待真实契约，不能客户端重算口径。已选作者关系的名称完整呈现需多作者详情字段。
- 数据存储/PWA安装/玻璃SVG折射的跨浏览器能力、原件解码与实际触控、桌面窗口/托盘/安装必须单独验收；云端合成测试不能替代。

## 动效与视觉边界

独立组件规范见 [ui/README](../ui/README.md)。连续导航只保留一个实时页面并取消旧动画；返回记录最多64项，POP恢复位置，未知前序回首页。焦点进入页面标题，图片dialog关闭恢复触发按钮。CSS有浅深色、减少动效、强制高对比与无backdrop-filter降级。

底栏使用真实背景模糊/透射；支持SVG backdrop组合的浏览器额外位移背景，移动透镜按实测尺寸响应式定位，图标具有选中放大与按压回弹。SVG折射支持不应由 `@supports` 一个布尔值冒充最终像素验证，需结合云端截图与目标浏览器设备观察；不支持时不会显示空导航或失去选中语义。
