## 动效与视觉边界

独立组件规范见 [ui/README](../ui/README.md)。连续导航只保留一个实时页面并取消旧动画；返回记录最多64项，POP恢复位置，未知前序回首页。焦点进入页面标题，图片dialog关闭恢复触发按钮。CSS有浅深色、减少动效、强制高对比与无backdrop-filter降级。

独立玻璃组件具有真实背景模糊/透射、可用时的 SVG 位移、选中透镜与按压回弹。当前 Web 不增加底栏；效果只能接在旧有导航形式上，不能改布局和导航内容。SVG 支持不能由 `@supports` 布尔值冒充像素验证，需要云端截图及目标浏览器观察。
