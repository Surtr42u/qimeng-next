## 需要继续接通的保留能力

这些是当前实施中的缺口，不是用户批准的功能删减；主代理与后端继续补齐后更新本表。

- 四维筛选、日期精确计数、来源词表、作者排序与总数已接新协议，待本轮云验；没有在客户端重复统计或推断区间。媒体详情/编辑、上传工作台、词表、库管理、备份与维护页面仍有视觉差异，必须逐页继续恢复。
- 完整服务监控/网络与存储明细、库移除、按目录分页文件整理、作者TXT镜像、资料目录与旧v2迁移界面仍待完整接通。扫描设置新契约已写入UI，等待主代理服务实现同批验证。
- 原生视频内核不新增。事件、时间轴与续播已有源码链路，但硬关闭浏览器可能丢失尚未完成本地事务的最后停留段，不能承诺浏览器存储永不回收；播放格式/设备仍需验收。
- 作者公开资料服务与 Web 链路已写入，迁入已知字段/离线头像转换待对应迁移服务接线并云验；详见 [作者资料](author-profiles.md)。作者新作自动抓取已按新需求明确不纳入，配置的公开发布入口保留，不把无源状态画成零更新。
- 处于长词表后页的已有关联保持ID、不被当作空集合丢弃；完整关联名称呈现仍需详情关系名称字段或对应单项查询，不能猜名字。
- 数据存储/PWA安装/玻璃SVG折射的跨浏览器能力、原件解码与实际触控、桌面窗口/托盘/安装必须单独验收；云端合成测试不能替代。

## 动效与视觉边界

独立组件规范见 [ui/README](../ui/README.md)。连续导航只保留一个实时页面并取消旧动画；返回记录最多64项，POP恢复位置，未知前序回首页。焦点进入页面标题，图片dialog关闭恢复触发按钮。CSS有浅深色、减少动效、强制高对比与无backdrop-filter降级。

独立玻璃组件具有真实背景模糊/透射、可用时的 SVG 位移、选中透镜与按压回弹。当前 Web 不增加底栏；效果只能接在旧有导航形式上，不能改布局和导航内容。SVG 支持不能由 `@supports` 布尔值冒充像素验证，需要云端截图及目标浏览器观察。
